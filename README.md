# Smart Study Planner

A command-line Python application for tracking study sessions, viewing statistics, and identifying subjects that need more attention.

## Features

- Add study sessions with subject, topic, date, and duration
- Classify sessions as Short, Medium, or Long
- View all logged sessions
- Search sessions by subject
- View total study time and subject statistics
- Save and load sessions from `study_log.txt`

## Requirements

- Python 3.7 or later

## Usage

Run the program from this folder:

```bash
python Study_Planner.py
